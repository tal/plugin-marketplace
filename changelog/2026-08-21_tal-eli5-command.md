# Add `/tal:eli5` command

**Date:** 2026-08-21
**Scope:** `plugins/tal/commands/eli5.md`, plugin and marketplace READMEs

## What changed

Added an `eli5` command to the `tal` plugin. Give it a topic and it asks the agent to explain
the subject for someone with no prior knowledge, presenting the result as an HTML artifact
with big pictures and few words.

## Inspiration

Adapted from [Thariq's ELI5 command shared on X](https://x.com/trq212/status/2090884854590382515).
