# Make references unambiguous

Rewrite the supplied document or passage so a reader can understand every reference and sentence structure on the first pass. Preserve the author's meaning, intent, emphasis, level of certainty, formatting, and voice. Improve only clarity of reference and grammatical structure; do not perform a general style rewrite.

## Editing guidance

- Examine every pronoun and demonstrative, including but not limited to *this*, *that*, *these*, *those*, *it*, and *they*. Each reference should have one immediately identifiable antecedent.
- Keep a pronoun or demonstrative when its referent is already unmistakable. When the reader would need to backtrack, replace the reference with the shortest natural noun phrase that removes the ambiguity.
- Check for more than one plausible grammatical reading, including unclear modifier attachment, coordination, scope, attribution, comparison, or ellipsis. Rewrite ambiguous syntax so only the intended reading remains.
- Infer the intended reading from surrounding context when the evidence is strong. Never silently choose among materially different meanings when the context does not resolve them.
- Make the smallest changes that solve the ambiguity. Avoid repetitive nouns, stiff prose, added explanation, or changes to terminology, tone, register, and rhythm unless a change is necessary for clarity.

## Output

Return the complete revised document first.

Add a brief **Ambiguities resolved** section only when the original contained sentences with multiple plausible grammatical readings. Identify each affected sentence and the reading the rewrite preserves. If the intended meaning cannot be determined safely, flag the unresolved wording and give concise alternative rewrites instead of guessing.
