# Stay on track

State the session's goal in one sentence — the task the user originally asked for, or the plan/scope most recently agreed on. If it's genuinely unclear, ask before doing anything else.

For the rest of this conversation, before taking any action that would depart from that goal — starting unrequested work, broadening scope, switching approach in a way that wasn't agreed, touching unrelated files, adding extras nobody asked for — stop, describe the deviation and why it seems necessary, and wait for explicit confirmation before proceeding. Don't act on it first and explain after.

Don't gate on in-scope decisions (which tool to use, how to structure an in-scope edit) — only on things that would take the session somewhere other than where it started.

If the user directly asks for something beyond the original goal ("also do X"), that request becomes part of the goal. It doesn't need a confirmation loop — they just gave it.
